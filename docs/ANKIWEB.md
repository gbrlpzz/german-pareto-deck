# AnkiWeb publication handoff

## Listing copy

**Title**

German Pareto Deck: frequent words in frequent sentence patterns

**Version**

v0.3

**Description**

A research-backed German Anki deck. It teaches 2,560 high-frequency word cards inside authentic
German sentences, plus 500 pattern cloze cards and 62 recognition cards for routines and modal
particles. Study Core first, then Patterns, then Extension. The release has no audio and does not
redistribute raw corpora.

**Decks**

- German Pareto::Core — 1,313 word cards
- German Pareto::Extension — 1,247 word cards
- German Pareto::Patterns — 562 pattern cards

**Source**

https://github.com/gbrlpzz/german-pareto-deck

## Upload steps

1. Build and verify the release locally.
2. Download `out/german-pareto-deck.apkg` or the GitHub release asset.
3. Sign in to AnkiWeb.
4. Open **Shared Decks -> Upload** and upload the `.apkg` file.
5. Paste the copy above. Add the GitHub and Zenodo links after they exist.
6. Download the public AnkiWeb copy once and import it into a clean Anki profile.
7. Check the three deck names, card counts, tags, and the absence of media.

AnkiWeb upload is an owner-gated account action. The project does not automate it.
